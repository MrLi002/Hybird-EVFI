# 实现对应与边界

## 已落实的规范

- 128-bin 全区间体素、16 个更新步骤、17 个升序节点。OF-AF 原事件编码和 BiFEB 保留参数名；全通道卷积后的分组不解释为完全独立的原始事件片段。
- 默认 Query 与节点顺序一致；legacy 模式逐项恢复源代码权重方向。新 warp 与旧半像素 warp 独立切换。
- BiW 保留原内部 hole 提示数值；诊断 hole 从 sum 覆盖量阈值化，导出 full coverage、采样有效性和前后向图像。
- CBMNet 编码器与通道注意力组件来自固定源文件。精修四个输入卷积适配 extras，三尺度输出为零初始化残差。
- EventAdapter 编码完整 128-bin 事件，缓存全区间特征，再按 `[t,1-t]` 与上下文条件化。
- BASR 分离 repair/support，默认 warped 参考，动态正弦编码、Query 分块、安全空 Key 和最终 MLP 清零；完整模块输出由 repair gate 控制。
- BASR 两级 head=4、2，支持 u=32/44。区域 SSIM 使用两级实际生效 gate 的并集，排除无可用 Key 的旁路区域。
- 前向流使用源图像引导平滑，后向流使用目标真值；光度损失按单通道有效像素归一化。LPIPS 保留预测梯度，权重冻结。
- 后向相关修正与源网格 splatting 度量独立开关，修正前后 Query 都导出；metric 必须有前向辅助监督。

## 为完整运行补充的工程部分

1. `ModelConfig` 统一保存结构开关，评测可从自训练 checkpoint 重建模型，原官方权重仍需显式选择 legacy 配置。
2. CPU PyTorch scatter_add splatting 是对同一运算的参考后端；原 CuPy 文件完整保留。GPU 数值和性能需在用户 CUDA 环境另测。
3. 两个数据集统一使用 OF-AF BS-ERGB 式的 images/events 布局、帧索引事件切片、裁剪后首末事件归一化与帧索引目标时刻。公开训练类返回通道打包的 tuple；RawVFIData 仅适配为现有训练器的具名字典。读取端不打开任何外部时间戳文本。
4. BS-ERGB 固定原坐标换算及 0/1 极性转换；GoPro 使用 x/y/t/p、像素坐标及 -1/+1 极性。必须提前整理为每个 RGB 间隔一个 npz，且事件时间轴连续。逐 skip 枚举替代原先随机 skip；默认全部训练目标，显式 num_targets 是独立的显存采样选项。数值精度、空事件与单时间戳边界使用本项目安全实现，不承诺逐位复现原事件工具。
5. 预训练 CBMNet 只加载键名/形状匹配的指定层，不加载不兼容输出头，也不使用 DSER++ 整网权重。测试不需要下载任何预训练权重。
6. 提供 epoch 级保存和恢复；没有对批次中途及预取 worker 状态作精确断点。CPU 测试验证了从 epoch0 checkpoint 恢复后下一轮参数与连续训练一致。
7. 关闭/开启模块的 staged transfer 使用 `weights_path`；resume 对模型配置和 data_protocol 作一致性校验。旧时间边界读取版本的断点可迁移权重，不作为同一数据流程续训。
8. 完整项目检查采用 CPU、低分辨率与部分缩小 bins/steps；独立覆盖默认节点设置、legacy 原代码输出和 Large 通道。真实训练收敛、显存、CUDA AMP、CuPy 编译和论文指标尚未验证。

## 科研解释

诊断掩码反映估计差异、投影覆盖或采样越界，不能当作真实可见性标签。保守支持 patch 可能使 BASR 频繁旁路；`basr_support_ratio` 是可记录的独立消融参数。相关模块先 warp 再邻域匹配，属于文档规定的近似，不是源对应点中心的精确相关查找。零初始化使新精修从粗融合开始，不能声称完整保留旧 B0 最终预测。
